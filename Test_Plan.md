# Test Plan

## Project Name
Online Banking Application

## Objective
To verify that all banking functionalities work as expected and meet business requirements.

## Scope
### In Scope
- Login
- Registration
- Fund Transfer
- Account Summary
- Transaction History

### Out of Scope
- Performance Testing
- Security Testing

## Test Types
- Functional Testing
- Smoke Testing
- Regression Testing

## Entry Criteria
- Application build available
- Requirements documented

## Exit Criteria
- All critical defects closed
- Test cases executed successfully

## Deliverables
- Test Cases
- Bug Reports
- RTM
- Test Summary Report
